# Festival ARC 2026 results

The active Festival ARC 2026 publication is served at `/` with `kind: final` in `editions.config.ts`.

The homepage displays the festival logo, “Selección Convocatoria Regional”, and “Revisa la resolución”, linking to `public/Rex-637-Formaliza-seleccion-y-no-seleccion-ARC 2026.pdf`. Application forms, deadlines, and call guidelines are no longer published.

Run `pnpm --filter festival-2026 dev` for development or `pnpm build` from the repository root for the composed site.
