Deterministic mocked tests are not visual, real-browser or assistive-technology proof. No browser/server/visual checks or stage-2 implementation are part of this unit.

D1–D20 and the historical catalog-only permission boundaries below remain decision provenance, not a reversal of the subsequent stage-1 authorization. ### Modal engineering recommendations, not new presentation approvals

Use `<dialog>.showModal()` for top layer/inert background/native focus containment, with an accessible name and sensible focus inside. Do not implement a second focus trap. Animate an **inner surface** transform/clip between captured source and measured final surface rects; do not displace the native dialog inconsistently out of browser centering. Use consistent viewport/scroll coordinates and independent text wrappers to avoid stretched glyphs or duplicate accessible titles; optional visual proxy is `aria-hidden` and noninteractive.

Retain the source node. Background scroll locks with its offset preserved; measure current source rect on close. Keep dialog/blocking active through reverse and call `close()` only after settlement; then restore source focus/scroll without jumps or double anchoring. Missing/disconnected origin uses safe fade and nearest valid focus fallback. Outside close requires both pointer down/up on the backdrop, not an inside drag. Close during opening reverses the current playhead; repeated close is idempotent, valid internal resume follows latest intent, and no background click can reopen or switch artists mid-close.

Confirmed presentation (D8): centered responsive modal, limited desktop width and nearly full mobile width with exterior margins, bounded by dynamic viewport/safe-area. Long body/description scrolls internally and header/close/actions remain reachable. When present, the secondary image sits beside the description on desktop and above it on mobile, with bounded image height; absent image leaves no blank media area. No full-screen mobile panel is selected; exact numeric dimensions remain tuning. Reduced motion applies immediate equivalent states; font/image/resize changes settle/rebase fresh endpoints safely. Reserve image aspect ratio, retain approved brand and distinguish description scrolling from locked background scrolling. The modal does not guarantee all scroll concerns disappear.
